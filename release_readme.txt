            P2P эмулятор локальной сети для игр

ВЕРСИЯ 2.3.5 (Antivirus Clean, Windows Manifest & Stability):
- Устранены ложные срабатывания антивирусов (False Positives): удалены эвристические триггеры PE-дроппера.
- Библиотека steam_api64.dll теперь поставляется в комплекте рядом с исполняемым файлом с поддержкой автозагрузки в %APPDATA%\LANForge.
- Добавлен официальный Windows Manifest (asInvoker, Per-Monitor DPI Aware v2, полная совместимость с Windows 10/11).
- Добавлены аутентичные метаданные Windows VERSIONINFO (версия 2.3.5.0, описание, компания, копирайт).
- Заменено принудительное завершение процессов на стандартный мьютекс Windows (Global\LANForgeSingleInstance).
- Полная синхронизация сетевой телеметрии пинга и автоматический backoff повторов Steam SDR.


Инструкция по запуску:
1. Запустите LANForge.exe (установка не требуется, права админа не нужны).
2. Один игрок создает комнату (например Minecraft), сообщает код другу.
3. Друг вводит код и подключается.
4. В игре:
   - Хост открывает одиночный мир для сети (Esc -> Открыть для сети).
   - Друг нажимает "Скопировать для Minecraft" и вставляет адрес 127.0.0.1:25565 в Сетевая игра -> Прямое подключение!

Особенности:
- Прямое P2P-соединение по UDP без прокси-серверов.
- Не требует установки виртуальных сетевых адаптеров и прав администратора.
- Интеграция с Discord Rich Presence.
- LAN-радар для поиска открытых локальных миров.
- Работает в фоновом режиме в системном трее Windows.
