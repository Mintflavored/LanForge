                       LANForge (v2.0.2)
            P2P эмулятор локальной сети для игр
========================================================================

ВЕРСИЯ 2.0.2 (Steam SDR Chunk Streaming & Stability Fix):
- Увеличен размер буферов отправки и приема Steam SDR до 32 МБ (по умолчанию было 512 КБ).
- Устранена ошибка k_EResultLimitExceeded (25) при передаче тяжелых пакетов мира/чанков Minecraft: добавлен плавный retry/backpressure цикл.
- Потокобезопасная прокачка сообщений без блокировок мьютексов во время сетевого ввода/вывода.
- Устранена ошибка Thread Starvation / Lock Contention в Steam Networking Sockets.
- Встроенный LAN-маяк Minecraft (224.0.2.60:4445): игровой мир автоматически отображается в меню сетевой игры у друзей.
- Кастомные векторные SVG-иконки и индикаторы статуса.

Инструкция по запуску:
1. Запустите LANForge.exe (установка не требуется, права админа не нужны).
2. Один игрок создает комнату (например Minecraft), сообщает код другу.
3. Друг вводит код и подключается.
4. В игре:
   - Хост открывает одиночный мир для сети (Esc -> Открыть для сети).
   - Друг нажимает "Скопировать для Minecraft" и вставляет адрес 127.0.0.1:25565 в Сетевая игра -> Прямое подключение!

Особенности:
- Прямое P2P-соединение по UDP без прокси-серверов.
- Не требует установки виртуальных сетевых адаптеров и прав администратора.
- Интеграция с Discord Rich Presence.
- LAN-радар для поиска открытых локальных миров.
- Работает в фоновом режиме в системном трее Windows.
