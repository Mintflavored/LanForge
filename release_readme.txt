LANForge — это высокопроизводительный P2P эмулятор локальной сети для игр
(Minecraft, Terraria, CS, Palworld, Valheim, Factorio и многих других).

[БЫСТРЫЙ СТАРТ]:
1. Запустите файл `LANForge.exe` (двойной клик).
2. Для создания сети нажмите "+ Создать сеть", выберите игру и скопируйте код комнаты.
3. Друзья нажимают "Войти по коду", вводят 6-значный код комнаты и подключаются.
4. В игре вводите адрес хоста (например, 10.42.0.1:25565).

[ОСОБЕННОСТИ]:
* Direct UDP P2P туннели без задержек и без центральных серверов реле.
* Полная устойчивость к прокси, VPN и Clash Verge (Proxy-safe).
* Discord Rich Presence — отображение игры, комнаты и пиров в вашем Discord.
* Встроенный LAN-радар — перехват и ретрансляция широковещательных игровых миров.
* Системный трей Windows и тактильные звуковые уведомления.
