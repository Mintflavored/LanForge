            P2P эмулятор локальной сети для игр

ВЕРСИЯ 2.3.3 (Startup Self-Healing & Session Fixes):
- Устранено зависание при запуске ("бесконечная загрузка"): автоочистка фоновых зависших процессов и самовосстановление порта 8787.
- Добавлен сторожевой таймер (watchdog) для гарантированного завершения процесса при закрытии окна.
- Исправлено сохранение прав хоста и виртуального IP 10.42.0.1 при микроразрывах связи (Session Resumption & Grace Period 45s).
- Восстановлена встроенная иконка приложения в Проводнике Windows, заголовке окна и на панели задач.
- Устранено создание мусорного файла steam_appid.txt при запуске приложения.
- Монолитный Pure Go бинарник с ультранизким потреблением оперативной памяти (~3 МБ).


Инструкция по запуску:
1. Запустите LANForge.exe (установка не требуется, права админа не нужны).
2. Один игрок создает комнату (например Minecraft), сообщает код другу.
3. Друг вводит код и подключается.
4. В игре:
   - Хост открывает одиночный мир для сети (Esc -> Открыть для сети).
   - Друг нажимает "Скопировать для Minecraft" и вставляет адрес 127.0.0.1:25565 в Сетевая игра -> Прямое подключение!

Особенности:
- Прямое P2P-соединение по UDP без прокси-серверов.
- Не требует установки виртуальных сетевых адаптеров и прав администратора.
- Интеграция с Discord Rich Presence.
- LAN-радар для поиска открытых локальных миров.
- Работает в фоновом режиме в системном трее Windows.
