========================================================================
                       LANForge (v2.3.6)
            P2P эмулятор локальной сети для игр
========================================================================

ВЕРСИЯ 2.3.6 (P2P Stability & Disconnect Fix):
- Полностью устранены периодические дисконнекты каждые ~60 секунд: удален агрессивный сброс памяти EmptyWorkingSet.
- Сняты ограничения Go runtime (SetMemoryLimit, SetGCPercent, GOMAXPROCS) — исключены микрофризы и троттлинг сборщика мусора.
- Таймаут соединений Steam SDR (TimeoutConnected) увеличен с 10 до 60 секунд (TimeoutInitial — до 30 секунд).
- Буферы отправки/приема Steam SDR расширены до 64 МБ, лимит сообщений — до 131 072.
- Переключено на Reliable send с объединением кадров в MTU-пакеты, лимит бэкпрешера увеличен до ~20 секунд.
- Включена гарантированная доставка данных перед закрытием сокетов (bEnableLinger = true).
- Буферы сокетов игры увеличены до 2 МБ.


Инструкция по запуску:
1. Запустите LANForge.exe (установка не требуется, права админа не нужны).
2. Один игрок создает комнату (например Minecraft), сообщает код другу.
3. Друг вводит код и подключается.
4. В игре:
   - Хост открывает одиночный мир для сети (Esc -> Открыть для сети).
   - Друг нажимает "Скопировать для Minecraft" и вставляет адрес 127.0.0.1:25565 в Сетевая игра -> Прямое подключение!

Особенности:
- Прямое P2P-соединение по UDP без прокси-серверов.
- Не требует установки виртуальных сетевых адаптеров и прав администратора.
- Интеграция с Discord Rich Presence.
- LAN-радар для поиска открытых локальных миров.
- Работает в фоновом режиме в системном трее Windows.
