                       LANForge (v2.5.0)
            P2P эмулятор локальной сети для игр
========================================================================

ВЕРСИЯ 2.5.0 (Anime Fighting: Multiverse, Profiles & Reconnect Fix):
- Добавлена встроенная поддержка и игровой пресет для файтинга "Anime Fighting: Multiverse".
- Реализовано P2P UDP-туннелирование и автообнаружение комнат по протоколу ANIME_FIGHT_ROOM_QUERY_V1 (порт 27846 UDP).
- Устранена бесконечная петля переподключения WebSocket и защищены уведомления о восстановлении связи с комнатой (дебаунс и отвязка обработчиков сокетов).
- Внедрена система настраиваемых профилей: выбор аватара, био игрока и мгновенная синхронизация присутствия в P2P-сети.
- Добавлена бессерверная система друзей с инвайтами в 1 клик и отслеживанием статуса (в сети, в комнате, играет).
- Улучшена обработка дисконнектов и стабильность работы сетевого ядра.


Инструкция по запуску:
1. Запустите LANForge.exe (установка не требуется, права админа не нужны).
2. Один игрок создает комнату (например Minecraft), сообщает код другу.
3. Друг вводит код и подключается.
4. В игре:
   - Хост открывает одиночный мир для сети (Esc -> Открыть для сети).
   - Друг нажимает "Скопировать для Minecraft" и вставляет адрес 127.0.0.1:25565 в Сетевая игра -> Прямое подключение!

Особенности:
- Прямое P2P-соединение по UDP без прокси-серверов.
- Не требует установки виртуальных сетевых адаптеров и прав администратора.
- Интеграция с Discord Rich Presence.
- LAN-радар для поиска открытых локальных миров.
- Работает в фоновом режиме в системном трее Windows.
