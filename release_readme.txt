========================================================================
                       LANForge (v1.6.0)
           P2P эмулятор локальной сети для игр
========================================================================

Быстрый старт:
1. Запустите LANForge.exe.
2. Для создания сети нажмите "+ Создать сеть", выберите игру и скопируйте 6-значный код.
3. Друзья нажимают "Войти по коду", вводят код комнаты и подключаются.
4. В игре подключайтесь по виртуальному адресу хоста (например, 10.42.0.1:25565).

Особенности:
- Прямое P2P-соединение по UDP без прокси-серверов.
- Не требует установки виртуальных сетевых адаптеров и прав администратора.
- Интеграция с Discord Rich Presence.
- LAN-радар для поиска открытых локальных миров.
- Работает в фоновом режиме в системном трее Windows.
