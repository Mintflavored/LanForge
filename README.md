# 🎮 LANForge — P2P Virtual LAN Gaming Hub (Go + Cyberpunk TUI Edition)

**LANForge** — это сверхбыстрая, легковесная замена **Radmin VPN** и **Hamachi** на **Go (Golang)** со стильным киберпанк интерфейсом в терминале (**Bubbletea + Lipgloss**).

---

## ⚡ Ключевые возможности:

- 🚀 **Один исполняемый файл `.exe`:** Никаких Node.js, Chromium, npm или WebView2. Занимает всего ~8 МБ памяти.
- 💬 **Cyberpunk TUI интерфейс:**
  - `[1] Лобби:` Карточки друзей, индикация пинга в мс (зеленый/желтый/красный), статус хоста, копирование IP.
  - `[2] Каталог игр:` 30+ готовых пресетов (Minecraft, Terraria, Palworld, CS, Valheim, Stardew Valley, Factorio, HOMM III и др.) с 1-клик созданием комнат.
  - `[3] Magic LAN Radar:` Перехват и ретрансляция пакетов `UDP 255.255.255.255` для автоматического появления серверов в играх.
  - `[4] Сеть & NAT:` Детекция типа NAT (STUN RFC 5389), авто-проброс портов UPnP IGD на роутере.
  - `[5] Чат комнаты:` Встроенный мессенджер комнаты для обмена ссылками и сообщениями.
- 🌐 **6-значные коды комнат (`LAN-XXXX`):** Мгновенное подключение друзей без ручной настройки сетей.
- 🛡️ **Виртуальная подсеть `10.42.0.0/24`:** `10.42.0.1` для хоста, `10.42.0.2..254` для участников.

---

## 🚀 Быстрый запуск

Готовые скомпилированные бинарники находятся в папке `bin/`:

### 1. Запуск сервера комнат:
```bash
.\bin\lanforge-server.exe
# Запустит сигнальный сервер на порту 8787
```

### 2. Запуск игрового TUI клиента:
```bash
.\bin\lanforge.exe
```
*(Или с кастомным ником: `.\bin\lanforge.exe -nick "Alex" -server "ws://localhost:8787"`)*

## ⌨️ Горячие клавиши TUI:

| Клавиша | Действие |
|---|---|
| `Tab` / `Shift+Tab` | Переключение между вкладками (Lobby, Games, Radar, Network, Chat) |
| `1` .. `5` | Прямой переход на вкладку |
| `C` | Создать игровую комнату |
| `J` | Войти в комнату по 6-значному коду |
| `L` | Покинуть комнату |
| `R` | Запустить повторный тест NAT и UPnP |
| `↑` / `↓` + `Enter` | Выбрать игру из каталога и создать под неё комнату |
| `Q` / `Ctrl+C` | Выход |
